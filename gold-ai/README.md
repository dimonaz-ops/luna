# GOLD AI Services — Landing Page

A clean, single-file landing page for GOLD AI Services. Dark theme with a
gold accent focus, built as a self-contained static page (no build step).

## Sections

- **Hero** — headline, value proposition, primary CTAs, and key stats
- **Services** — six focused AI offerings
- **Process** — a three-step "golden path"
- **Why Us** — differentiators
- **CTA** — book-a-call conversion block

## Viewing

Open `index.html` directly in a browser, or serve the folder statically:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000/gold-ai/
```

Everything (styles, fonts link, and a small scroll-reveal script) is inline
in `index.html`. Reveal animations are progressive enhancements — all content
is fully visible without JavaScript.
